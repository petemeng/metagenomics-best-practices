# Small, versioned inputs

Files in this directory are small enough to ship with the tutorial and are
either derived deterministically from a public source or are literature-backed
evidence tables.

## Article 01

- `01-crc-cohort-summary.tsv` is regenerated by
  `scripts/prepare_intro_data.R` from `meta_all.tsv` in Zenodo record
  `3517209` (version 1.0, CC BY 4.0, MD5
  `da18b10fdabae6308329e80b73991f84`).
- `01-assay-evidence.tsv` encodes the measurement-boundary synthesis used in
  the opening heatmap. Values are `0 = not directly measured`,
  `1 = conditional or inferred`, and `2 = directly supported by that assay`.
  The synthesis is based on Quince et al. 2017, Knight et al. 2018, and the
  Integrative Human Microbiome Project 2019; it is not a biological abundance
  table.

The committed summary allows the website to render without a live download.
The QA workflow independently downloads and checks the source, regenerates the
summary, and renders from that regenerated copy.

## Article 02

- `02-layer-capabilities.tsv` is the literature-backed decision matrix used to
  distinguish read profiling, gene/contig-centric, and genome-resolved evidence
  objects. Scores are an explicit teaching rubric, not measured biological
  values.
- `02-published-anchors.tsv` records scale values reported by Wirbel et al.
  2019 and Almeida et al. 2021.

## Article 03

- `03-crc-design-audit.tsv` is regenerated by
  `scripts/prepare_article03_data.R` from the same checksum-locked
  `meta_all.tsv` source used by article 01.
- Each row is one Study × outcome arm. Counts and covariate-completeness fields
  are aggregated from the public metadata; the table contains no simulated
  microbiome effects.
- The QA workflow regenerates this table from Zenodo before isolated rendering.

## Article 04

  `scripts/prepare_article04_data.R` from the same checksum-locked Wirbel
  metadata. It contains all 768 analysis samples and the public
  `Library_Size` field; that field is not relabeled as a uniform post-QC or
  non-host denominator.
- `04-lake-lanier.npo` is the unmodified `LakeLanier.npo` package example from
  Nonpareil tag `v3.5.5`. Its SHA-256 is
  `8db00c35eadb64c36eaccad35007c9e7a5d553efb0d5c12b6f859ab1097f52f4`.
  The immutable URL, Git blob SHA, and Artistic License 2.0 notice are recorded
  in `04-nonpareil-data-NOTICE.txt`.
- `04-lake-lanier-coverage.tsv` is regenerated from that `.npo` file using the

  does not include a model projection beyond 1.17 Gbp.

  et al. 2019 for broad taxonomy, AMR gene-family richness, and AMR allelic
  richness. These values are literature evidence, not universal sequencing
  recommendations.
- The QA workflow independently regenerates both derived tables, checks the
  audited metrics, and renders the chapter from the regenerated copies.
