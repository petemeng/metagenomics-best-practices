Article 16 data and evidence notice
===================================

Input reads
-----------
This chapter reuses the checksum-locked clean paired FASTQ produced for
Article 13 from the first 100,000 synchronized pairs of ENA run ERR9765746
(PRJEB52977; SAMEA14435832), a 71-strain MOCK1 DNA library described by
Meslier et al. (2022), Scientific Data, DOI 10.1038/s41597-022-01762-z.
fastp retained 99,991 pairs. The FASTQ files remain in data/raw/ and are not
committed. Article 16 independently verifies the compressed SHA-256 values,
record counts, base counts, paired identifiers, and one-output-row-per-pair
Kraken contract.

Reference database
------------------
The one-time run uses the release-specific Standard-8 database dated
2026-06-26 from the Langmead Lab AWS Index Zone. Its archive is fixed by
5,946,578,575 bytes and MD5 7685f43cce057c2ca18511c925399b72. Standard-8
contains RefSeq archaea, bacteria, viruses and plasmids, human, and
UniVec_Core, but caps the Kraken index at 8 GB. The cap reduces RAM at a
documented cost in sensitivity and accuracy; this result is not presented as
equivalent to the full Standard or core_nt database. The archive includes
Bracken distributions for 50, 75, 100, 150, 200, 250 and 300 bp reads. All
17 published internal-file MD5 values are retained in
data/small/16-standard8-files.md5.

Software identity
-----------------
The environment fixes Kraken2 2.17.1 and the Bioconda Bracken package 3.1p1.
The upstream Bracken v3.1 wrapper still prints "Bracken v3.0.1" from its
embedded VERSION variable; both the package identity and CLI-reported string
are recorded rather than silently rewriting either one.

Interpretation boundary
-----------------------
Kraken2 classifies paired input as one fragment per synchronized pair.
Bracken statistically redistributes compatible higher-rank classifications
to a requested rank; it does not realign reads, prove strain identity, create
absolute abundance, or rescue organisms absent from the database. MOCK1 is a
real benchmark label, but this chapter does not claim a complete current-NCBI
strain-to-taxid truth set. Database and confidence false-positive auditing is
reserved for Article 17.

Public bundle
-------------
Only aggregate Kraken/Bracken reports, audit tables, normalized logs,
resource measurements, and checksums are frozen. Raw FASTQ, the database
archive and index, and per-fragment Kraken output are excluded from Git.
Routine QA is network-free and reads only the frozen evidence bundle.
