Article 08 data, license, and provenance notice
================================================

1. Biological source and study license
--------------------------------------

All three platform comparisons in Article 08 refer to the same synthetic
MOCK1 DNA sample:

- Study: Meslier V, Quinquis B, Da Silva K, et al. Benchmarking second and
  third-generation sequencing platforms for microbial metagenomics.
  Scientific Data. 2022;9:694.
- DOI: https://doi.org/10.1038/s41597-022-01762-z
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- ENA project: PRJEB52977.
- ENA sample: SAMEA14435832.
- Biological material: MOCK1, an uneven synthetic metagenome made from DNA
  of 71 microbial strains.

The platform benchmark table transcribes MOCK1 values reported in Tables 1-3
of the paper and joins them to official ENA run totals. No result was measured
from figure pixels. Platform-specific assemblers and unequal read budgets were
used in the source study, so the assembly comparison is observational and is
not interpreted as a platform-only causal effect.

3. Deterministic prefix and its limits
--------------------------------------

Selection rule:

  first 5,000 complete FASTQ records in each checksum-identified ENA file

Illumina R1 supplies the platform-level prefix metrics; R2 is streamed
separately to prove that the first 5,000 normalized read identifiers and their
order match R1. The ONT and PacBio streams each contribute 5,000 single reads.
This produces 15,000 metric rows and four display records.

The selection is deterministic but not random. It is suitable for checking
FASTQ grammar, mate synchronization, quality decoding, and the existence of
kilobase-scale reads. It is not a statistically representative subsample of
each run, a full-run yield estimate, or a specification for a current
sequencing product. Full-run means, mapping identity, and assembly outcomes
come from the paper/ENA benchmark table, not from the 5,000-record prefixes.

4. Metadata discrepancies and historical boundary
--------------------------------------------------

The published Table 4 prints the Illumina MOCK1 accession as ERR9765446.
That identifier did not return a run record in the official ENA project
metadata checked on 2026-07-19. The project metadata identify ERR9765746 for
the HiSeq 3000 MOCK1 run, and the accession, URLs, MD5 values, read count, and
base count used here all refer to ERR9765746. The difference is reported as a
source-table accession typo; it is not silently corrected.

The paper describes the PacBio experiment as Sequel II CCS, whereas the ENA
run metadata instrument-model field is "Sequel". Article 08 reports both
statements and does not manufacture a more specific archive value.

The ONT benchmark used a historical MinION R9 workflow and reported 89.08%
mean end-to-end mapped identity. That value is evidence about this 2022
benchmark dataset, not a claim about current ONT chemistry or current Dorado
models. Current ONT workflows retain POD5 raw signal and normally emit
basecalled BAM; FASTQ is an optional reduced representation. Current PacBio
HiFi workflows likewise use standardized BAM as the information-rich
container. Vendor format documentation was checked on 2026-07-19 and is
linked in the article.
