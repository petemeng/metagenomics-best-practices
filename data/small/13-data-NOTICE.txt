Article 13 real-data and frozen-output notice
================================================

Public source
-------------

This chapter uses the Illumina paired-end run ERR9765746 from the 71-strain
MOCK1 DNA sample SAMEA14435832 in ENA project PRJEB52977. The source study is:

Meslier V, Quinquis B, Da Silva K, et al. Benchmarking second and
third-generation sequencing platforms for microbial metagenomics.
Scientific Data. 2022;9:694. doi:10.1038/s41597-022-01762-z.

The article and associated benchmark data are distributed under CC BY 4.0.
The two official ENA FASTQ URLs, complete-archive MD5 values and compressed
byte counts are recorded in data/small/13-source-manifest.tsv.

Deterministic subset
--------------------

The one-time builder streamed the first 100,000 complete records from each
official FASTQ on 2026-07-20. It normalized read identifiers, required R1/R2
identity and order to match, and wrote deterministic gzip files with mtime=0
to scratch. The selection is a file prefix, not a random sample and not an
estimate of full-run performance.

Environment and command boundary
--------------------------------

The native Linux run used:

- FastQC 0.12.1
- fastp 1.3.6
- MultiQC 1.35
- Python 3.14.6
- OpenJDK 25.0.2
- four worker threads

Environment YAML SHA-256:
3d94a0e5e8a8b1ba2bf58de1d1c15be06824ae7163965559fce48ce632e94759

Linux-64 explicit lock SHA-256:
19bd7992dd9480fbd0fea34fda676da866c3775648a693fc6822636da64f2368

The explicit lock contains 171 package URLs. The exact one-time commands are
frozen as data/small/13-qc-frozen/commands.sh. fastp used paired-end adapter
detection, Q20 as the qualified-base threshold, at most 40% unqualified
bases, at most five N bases, and a minimum retained length of 50 bp. Poly-G
trimming, sliding-window end trimming, overlap correction, deduplication and
low-complexity filtering were not enabled. Zero adapter-trimmed reads is the
observed result, not a missing analysis step.

Observed result
---------------

The input contained 100,000 synchronized read pairs. fastp retained 99,991
pairs (99.991%) and removed nine because at least one mate was shorter than
50 bp. It removed no pair for low quality, excessive N content, adapter
dimer status or excessive length. The read-count ledger balanced exactly.

Combined Q30 base fraction was 0.899032 before and 0.899034 after filtering.
fastp reported a 0.01513 duplication fraction and a 265-bp insert-size peak;
reads were not deduplicated.

All four FastQC 0.12.1 reports contained 11 module states. Across raw R1,
raw R2, clean R1 and clean R2 there were 36 PASS, eight WARN and zero FAIL
states. The WARN states were Per sequence GC content and Sequence Length
Distribution in every report. A multi-genome mock community need not have
the unimodal GC distribution expected by FastQC's generic model, and this
file prefix contains natural 47-150-bp read-length variation. These WARN
states are diagnostic context, not automatic evidence of contamination or
run failure.

Frozen-output and resource boundary
-----------------------------------

Raw and clean FASTQ files remain in ignored scratch storage and are not part
of the versioned evidence bundle. The frozen bundle contains reports, logs,
machine-readable summaries and checksums only. Its 57 payload files pass the
manifest in data/small/13-qc-frozen/file-checksums.sha256. SHA-256 of that
manifest is:

0d21772cd4c017c96e04f97d17aff41560030a084b23c8bc93e6c634a164a965

Host-specific absolute paths and the one-time MultiQC temporary directory are
normalized in committed text reports to ${PROJECT_ROOT}, ${RAW_DIR},
${FROZEN_DIR}, ${READ_QC_ENV_PREFIX}, and ${TMPDIR}. Numeric results,
parameters, filenames and report content are otherwise unchanged. Routine QA
fails if the current project/environment path or a transient /tmp/tmp* path
appears in the frozen text payload.

Observed one-time resource use:

- FastQC before filtering: 0:04.39, 410,644 KB maximum RSS
- fastp: 1:17.91, 1,580,964 KB maximum RSS
- FastQC after filtering: 0:04.42, 423,296 KB maximum RSS
- MultiQC: 0:02.37, 222,508 KB maximum RSS

These measurements describe this 100,000-pair prefix on one machine. They
must not be multiplied into a universal full-run resource estimate without
benchmarking the target storage, compression, read geometry and concurrency.
Routine tutorial QA verifies the frozen SHA-256 manifest and performs no ENA
network access.
